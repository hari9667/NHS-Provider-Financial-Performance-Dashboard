##NHS Provider Financial Performance Dashboard -
An end-to-end NHS provider financial analysis project using Python, SQL, SQLite and Power BI.

##Project Overview -
This project analyses NHS provider financial performance for 2024/25 using NHS England provider financial data.
The project demonstrates an end-to-end data analytics workflow:
Raw Data → Python ETL → SQLite → SQL Analysis → Financial Validation → Power BI Dashboard

##Business Objectives -
Analyse NHS provider income and financial performance
Identify trusts with the largest surpluses and deficits
Compare provider income between 2023/24 and 2024/25
Analyse operating expenses and financial efficiency
Identify regional financial performance patterns

##Data Pipeline -
Extracted NHS provider financial data from NHS England
Cleaned and transformed the data using Python
Designed a relational database structure
Loaded the processed data into SQLite
Used SQL joins, window functions and year-on-year calculations
Validated financial figures using arithmetic reconciliation
Built an interactive Power BI dashboard
